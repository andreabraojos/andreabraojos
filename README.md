# Portfolio de Andrea Braojos

**Autora:** Andrea Braojos  
**URL:** https://andreabraojos.github.io/andreabraojos/

Portfolio personal desarrollado en HTML5 para la asignatura Desarrollo de Web y de Apps.

## Páginas

- **index.html:** presentación personal, habilidades, formación y proyectos destacados.
- **proyectos.html:** proyectos de desarrollo web, programación y análisis de datos.
- **contacto.html:** formulario de contacto en HTML, correo y enlaces profesionales.
- **sobre-mi.html:** trayectoria, cita, línea de tiempo, vídeo, preguntas frecuentes e indicadores de nivel.

## Recursos y fuentes

- **Vídeo:** *The Psychology of People Who Want to Do Everything*, incrustado desde YouTube: https://www.youtube.com/watch?v=3NGL3K6_iEk
- **Audio:** no se ha incluido una canción.
- **Tipografía:** Nunito, de Google Fonts, enlazada con `display=swap`.
- **Logo y favicon:** monograma AB creado en SVG y exportado a PNG para el favicon.
- **Portada e imagen Open Graph:** imagen creada para este portfolio con asistencia de generación de imágenes por IA.
- **Capturas de proyectos:** materiales de los proyectos y prácticas presentados en el portfolio.
- **Iconos de correo, GitHub y LinkedIn:** [Tabler Icons](https://github.com/tabler/tabler-icons), distribuidos con licencia MIT.

## Características

HTML semántico, navegación con teclado, enlace para saltar al contenido, imágenes con dimensiones declaradas y carga diferida donde corresponde, portada WebP con respaldo PNG y metadatos para buscadores y redes sociales.

Esta entrega no incluye CSS propio ni JavaScript.
